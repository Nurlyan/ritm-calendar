# Ритм · Совместный календарь

Сайт: https://nurlyan.github.io/ritm-calendar/

## Доступ

По явному выбору владельца вход работает по одному email, без писем и паролей. Email не подтверждается: любой знающий email владельца может открыть его профиль, менять календарь и читать дневник. Это упрощённый выбор профиля, а не подтверждение личности.

Устройство сохраняет выданную базой сессию на срок до 365 дней. Выход удаляет эту сессию; очистка данных браузера потребует повторного ввода email. Профиль девушки получает только просмотр календаря и истории; дневник ему не возвращается. Ограничения применяются на стороне базы, но знание email владельца позволяет выбрать его роль.

## Хранение

Рабочая база Supabase настроена через email-access.sql. Таблицы ritm_calendar, ritm_profiles, ritm_sessions и ritm_sleep закрыты для прямого чтения. Сайт использует ограниченные RPC-функции с публичным ключом. Секретных ключей в файлах нет. Email профилей хранится в базе в виде хэшей, сессии также хранятся хэшированными.

Обновления проверяются каждые 5 секунд, пока вкладка видна. Это периодический опрос, не WebSocket real-time. Одновременные записи защищены проверкой версии. При отсутствии сети изменения не сохраняются; офлайн-редактирование не поддерживается. Локальные записи из старой версии автоматически не переносятся.

## Установка

На iPhone: Safari → Поделиться → На экран «Домой». На Android и компьютере: меню браузера → Установить приложение / Добавить на главный экран. manifest.webmanifest и иконки позволяют отдельный запуск. При первом запуске установленного приложения может потребоваться ещё раз ввести email. Для работы требуется интернет.

## Календарь

Подъём 09:30, граница дневных блоков 00:30, отход ко сну 00:30–00:45. Во вторник созвон 20:00–21:20. Проверки на клиенте и в базе запрещают пересечения и нарушение этих границ. Переносы показывают новый план до сохранения; непоместившиеся занятия остаются в списке переносов. Базовый спорт Пн/Чт/Пт/Сб. Среда и четверг могут обменяться расписаниями; фактически начатые дни так менять нельзя.

Дневник содержит время отхода ко сну, подъёма, качество и заметки. Анализ показывает длительность между указанными отметками и среднее качество. Это не измерение фактического сна. Основной календарь работает по Москве, поля сна используют часовой пояс устройства.

## Публикация и проверка

GitHub Pages: main → / (root). Изменения публикуются стандартным workflow pages build and deployment. Для проверки правил: node --test tests.mjs. Для локального просмотра: python -m http.server 4173 --bind 127.0.0.1.

supabase.sql — исходная неиспользуемая схема с подтверждаемым входом; рабочая реализация находится в email-access.sql. Схема применяется один раз. Не запускайте её повторно в существующей базе.
